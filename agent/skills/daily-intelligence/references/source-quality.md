# Source Quality 與 confidence

## 權威階梯

由高到低。判斷的是**對這個特定事實**的權威性,不是來源的整體聲譽。

| 層級 | 說明 | 典型 sourceType |
|---|---|---|
| **1. 一手 / 官方** | 事件當事方自己發布:公司公告、release notes、官方 blog、監管機關文件、法院裁定、公司申報文件 | `github`、`sec`、`rss`(官方 feed)、`fred`、`coingecko` |
| **2. 維護者 / 作者本人** | 專案 maintainer 的說明、論文作者的貼文、當事工程師的 post-mortem | `arxiv`、`semantic-scholar`、`github`(issue/discussion)、`hackernews`(作者本人回覆) |
| **3. 具查證能力的技術媒體** | 有署名、有獨立求證、會更正的技術刊物 | `rss`、`web` |
| **4. 聚合討論** | HN 討論串、Reddit 主題串。有時包含極高品質的內行分析,但沒有編輯責任 | `hackernews`、`reddit` |
| **5. 匿名社群 / 未署名內容** | 匿名爆料、無來源的轉述、演算法農場內容、未署名影片 | `reddit`、`youtube`、`web` |

### 重要的例外

階梯不是死的:

- **官方來源在講自己的產品優劣時不是中立的。** 廠商自評 benchmark 屬層級 1
  的「他們確實這樣宣稱」,但屬層級 5 的「這是真的」。
  在 story 裡要分清楚「X 宣稱」與「X 做到」。
- **HN 上某個領域專家的長回覆,在技術機制上可能比媒體稿更可靠。**
  但它仍不是事件事實的權威來源 — 它是解釋的好來源,不是事實的好來源。
- **`sec` 與 `fred` 這類是最高權威**,因為它們是紀錄本身,不是關於紀錄的報導。

## confidence 怎麼給

`confidence` 回答:**「這則 story 陳述的事實,有多大機率成立?」**
不是「這件事多重要」,也不是「我寫得多有把握」。

| 情境 | confidence |
|---|---|
| 官方一手文件 / 申報 / 正式紀錄,內容明確 | 0.9 – 1.0 |
| 官方公告,但關鍵細節模糊或有解讀空間 | 0.75 – 0.9 |
| 兩個以上獨立的層級 3 來源一致報導,無官方否認 | 0.7 – 0.85 |
| 單一技術媒體報導,引用具名消息來源 | 0.55 – 0.7 |
| 單一媒體報導,引用「知情人士」 | 0.4 – 0.55 |
| 聚合討論上的一致觀察(例如多人回報同一故障) | 0.4 – 0.6 |
| 匿名爆料、單一未證實來源 | 0.15 – 0.35 |
| 當事方已否認,但報導方未撤回 | 0.1 – 0.3 |

### 會拉低 confidence 的訊號

- 全部 item 都源自同一則原始報導(七篇媒體稿轉述同一個獨家 → 實際只有 1 個來源,
  不要因為有七則 item 就加分)。
- 沒有具體數字、日期、或可查證的細節。
- 當事方被詢問但拒絕回應。
- 事實主張與已知的公開紀錄不一致。

### 會拉高 confidence 的訊號

- 有可獨立查證的成品(commit hash、release tag、公開文件編號、鏈上交易)。
- 當事方雖未主動公告,但有間接動作佐證(文件已悄悄更新、endpoint 已可呼叫)。
- 有對應的 structured fact 可引用。

## 報導互相矛盾時

**不要取平均。** 「A 說 500 人、B 說 2000 人,所以大概 1250 人」是編造。

正確做法:

1. **用階梯裁決。** 層級高的優先。官方說 500、匿名爆料說 2000 →
   採官方,並在 `reason` 記下有更高的未證實數字在流傳。
2. **同層級矛盾則兩邊都寫。** 兩家同等可靠的媒體給出不同數字 →
   `canonicalTitle` 不放數字,在 story 的 `reason` 與 brief 的 `whatHappened`
   裡並陳:「A 報導為 X,B 報導為 Y,雙方未說明差異來源。」
   `confidence` 因此下修。
3. **矛盾本身可能就是事件。** 官方說法與現場回報明顯不符,
   這個落差值得寫進 `whatHappened`,而不是被抹平。
4. **數字一律走 `factRefs`。** 有 structured fact 就引用 factId,
   不要在文字裡自己寫數字。沒有對應 fact 的數字,寧可用文字描述量級
   (「數百人規模」),也不要憑 prose 複述一個精確值。

## primarySourceIds 與 confidence 的關係

`primarySourceIds` 指向你用來裁決事實的那個來源。
如果你的 primary 只能選到層級 4 或 5,`confidence` 就不該高於 0.6。
兩者不一致(primary 是匿名 Reddit 貼文但 confidence 給 0.9)是明顯的內部矛盾。
